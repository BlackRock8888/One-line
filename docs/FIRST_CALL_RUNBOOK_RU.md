# Первый звонок без карты и подписки

Транспорт: собственный WebRTC (аудио напрямую между устройствами) + Node-сигнализация этого репозитория + публичные STUN (Google/Cloudflare, без аккаунта). Daily оставлен в коде, но не используется: вход блокирует `account-missing-payment-method`.

## Запуск (Mac)
```bash
npm start            # http://localhost:3000
ssh -R 80:localhost:3000 nokey@localhost.run   # временный HTTPS-адрес, без аккаунта
```
Откройте выданный https-адрес на телефоне A (мобильный интернет), нажмите «Создать комнату», отправьте ссылку на устройство B (другая сеть). Микрофон нужен только по HTTPS.

## Ограничение
Только STUN: при симметричном NAT/CGNAT (часть мобильных сетей, корпоративный Wi‑Fi) прямое соединение не установится — в журнале состояние `failed`. Тогда нужен TURN: `TURN_URLS`+`TURN_SECRET` (свой coturn) или `ICE_SERVERS_JSON` (например Cloudflare Realtime TURN или LiveKit Cloud Build — аккаунт бесплатный, карта не требуется по их условиям, но аккаунт создаёт владелец).

## Vercel
Статика на Vercel работает, но комнаты живут в памяти одного процесса: задайте `SIGNALING_ORIGIN` (https-адрес запущенного `npm start`) — иначе сайт ответит «Сервер комнат не подключён».
