# Brand structure

BlackRockLab is the parent ecosystem. Black Rock Talk is its voice-room product. One-line is the existing technical repository name and is not renamed.

The interface displays BLACKROCK LAB as the ecosystem wordmark and Black Rock Talk as the product name. The document title and metadata continue to name Black Rock Talk.

The exact ecosystem logo must be copied from the user's supplied mark.png without redrawing, recoloring or altering its proportions; its Mac paths are listed in BRAND_ASSET.md. That file has not yet been accessible in the cloud workspace. Existing fox assets remain preserved.
